## Why

`use-wc` library provides web components and CSS styles don't cross over to the shadow DOM. To workaround this, we can provide opinionated theming built from the basis of CSS custom properties (aka, CSS variables). This approach will allow adopting teams to utilize their own design system core and alias tokens.

## Principles

### Class names

Classes should be used as variance modifiers for semantic components. Instead of using custom attributes like `data-variant="primary"` and `data-size="small"` or long form class names like `btn-primary` and `btn-sm`, use classes like `primary` or `small` and apply the styles with the semantic element names, like `button.primary` or `button.small`.

Every component will have **base** styles that are applied when there are no classes, and the modifying classes will be applied as overrides to the base.
