use-shell is a generic flex-column-with-one-growing-region primitive — every direct child defaults to a fixed size, and use-shell-fill is the one region that grows to fill remaining space and scrolls its own overflow. Like use-field/use-selector, it's styled by tag name but isn't a registered custom element.

dialog, use-card, and [popover] use the same mechanic directly — no use-shell wrapper needed inside them, since they're already the flex container. They also get a shared header/footer/figure region treatment (avatar sizing, trailing-action pinning, a footer rule) that use-shell itself doesn't apply elsewhere, since that's a surface-specific convention, not a generic layout one. use-card replaces a .card class: like use-shell, it's a theme-only tag with no registration — an author can still add role/ARIA directly on it for real semantics, just not for free the way article/section give an implicit landmark.
