use-field pairs a label, a form control, and an optional helper/error p into one themed layout — label above the control, helper text below, switching to the invalid color automatically once the control is :user-invalid or carries aria-invalid="true". Like use-card, it's styled by tag name but isn't a registered custom element: a pure CSS layout hook, chosen over a class to avoid colliding with an author's own field-wrapper class names.
